## 本轮发现并修好的

1. **暂停顺延不完整**（第 3 部分 §18"赛季暂停期间的截止时间自动顺延"）：原来只有计划事件顺延，进行中的争夺的截止时间、仙品竞价的结束时间、辩论的持方和立论截止都不动——暂停一天，孩子就少了一天。现在恢复时一起顺延。
2. **删除孩子不彻底**（第 8 部分第 4 节"注销后删除"）：原来只删昵称、文件、作品、消息，孩子写的每日任务讲解、知识卡片、问卷答案、周月报告、赛季回顾都还在。
3. **查看记录有缺口**：找孩子（含家长手机号）、报名名单和导出、分组、赛季回顾预览、家长申请原来不记。
4. **操作日志有缺口**：复核打分、裁定、改判、AI 配置、提示词、每日任务异常处理、公告、二维码、内容安全处理原来不进操作日志。
5. **复核员权限**：参数、日历、计划事件复核员也能读（第 7 部分第 0 节说复核员没有）；题库的"题不够的地块"复核员反而打不开（应该只读可见）。
6. **学生端登录有效期**：第 3 部分 §20.7 是 180 天，代码是 365 天。
