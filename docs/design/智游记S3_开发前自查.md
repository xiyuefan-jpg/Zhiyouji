## 2. Claude 按默认值补上的规则

写进了 PRD 第 3 部分第 20 节"补充规定"，全部是参数或可以在管理端改。要点：

- **时间边界**：
  - 开营日必须是周日；
  - 每日任务从 D1 开始产粮草；
  - 领地收益从 D1 晚上 12 点到 D33 晚上 12 点；
  - 全员参与奖只算第 1–4 周（和模拟器一致）；
  - "进行中的进攻"算到结算完成为止（和模拟器一致）。
- **两处时间不一致已修正**：
  - 中心地 D8 开放改为早间公布时刻（原写 00:00）；
  - 周战争"开始"统一为周五早间公布时刻（原写 08:00）。
- **法宝**：
  - 七宝紫金钵对多个目标时，辟火罩、照妖镜分别结算；
  - 太虚幻镜能复制被触发的被动法宝，不能复制自己；
  - 三昧真火在地块换主人后停止转产出。
- **周战争**：平局时玉净瓶和大闹天宫算用掉；没交作品但激活了玉净瓶的一方不扣分。
- **大团战**：
  - "夺产出"按地块的基础产出算；
  - 主战场作品由阵营里任何组长、副组长或使者提交。
- **作品**：
  - 内容安全不通过只影响展示，不影响评分；
  - 上传上限：视频 10 分钟 / 500 MB，图片 9 张。
- **团队分精度**：原来按 0.1 分存，装不下领地递减（第 4 块地 0.36 分），改为按 0.01 分存，显示仍保留 1 位小数。
- **其他**：
  - 改判只在地块之后没再被争夺时自动重算；
  - 奖学金取整的差额给第 1 名；
  - 登录有效期 180 天。

## 3. 技术上要注意的（不需要你决定，记下来写代码时照做）

| 事项 | 做法 |
|---|---|
| 推送 | Expo 自带的推送在国内用不了。要接个推或极光的原生 SDK，所以 app 必须用 Expo 的自定义构建，不能用 Expo Go 调试 |
| app 内更新 | Expo 官方的更新服务器在国外，国内访问可能不稳定。改为把更新包放在我们自己的阿里云存储上（Expo 支持自建更新服务器） |
| 隐私合规 | 同意隐私政策之前，连"检查更新"、崩溃统计这类请求也不能发往第三方。崩溃统计用国内服务（例如阿里云），放在同意之后初始化 |
| 给管理员、复核员发邮件 | 用阿里云邮件推送，能发到海外邮箱 |
| 模拟器同步 | Python 模拟器还是规则定稿前的版本。写规则引擎之前，先把它更新到第 3 部分 v1.0.1，再对拍 |
| app 名称 | 搜索没有找到同名的"智游记" app，但不能确定。开通苹果开发者账号后，第一时间在 App Store Connect 里占用名称；国内商店以 APP 备案的名称为准 |
