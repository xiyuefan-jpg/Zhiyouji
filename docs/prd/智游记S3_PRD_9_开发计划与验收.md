## 1. 开发顺序

| 顺序 | 模块 | 做完的标志 |
|---|---|---|
| 1 | **地基**：仓库结构、`CLAUDE.md`、`PROGRESS.md`、自动测试、本地一键启动 | 自动测试能跑 |
| 2 | **Python 模拟器同步**到第 3 部分 v1.0.1 | 模拟结果和《数值设计》的验证结果在同一范围 |
| 3 | **规则引擎**：第 3 部分全部规则（纯函数）、参数表、机器人小组、加速模拟赛季 | 单元测试、不变量、对拍全部通过；33 天赛季约 1 小时跑完、账本平衡 |
| 4 | **服务器**：数据库（第 4 部分）、账号与登录、计划事件、账本、各玩法接口、文件上传 | 接口测试通过；用模拟时钟能把一个赛季从头跑到尾 |
| 5 | **管理端**：第 7 部分全部页面 | 你用测试账号建赛季、开通、分组、复核、干预 |
| 6 | **学生端 app**：第 5 部分全部页面 | 你在手机上走通注册 → 每日任务 → 进攻 → 结算 |
| 7 | **AI 处理**：第 6 部分的 10 个 AI 任务、AI 网关、内容安全 | 用你的样例作品试跑；主模型故障时自动切到备用模型 |
| 8 | **上线准备**：部署到阿里云、商店提交材料、三份文件、内容录入 | 第 3 节的开营条件全部满足 |

- 第 4–7 步会交叉进行。例如做学生端时，发现接口缺什么就回去补。
- 需要外部账号才能接通的部分（短信、推送、AI、文件存储），先用模拟的假服务开发；你开好账号后再换成真的。

## 2. 测试

| 测试 | 做什么 | 为什么不能省 |
|---|---|---|
| 规则引擎单元测试 | 第 3 部分每条规则、第 18 节的边界情况、第 20 节的补充规定 | 规则错了直接影响排名和奖学金 |
| 不变量 | 粮草不为负，余额等于账本合计；每块地最多一个主人、一场争夺；同一事件执行两次不重复记账 | 账本错了很难事后追回 |
| 和 Python 模拟器对拍 | 约 50 个典型场景逐笔对账；各跑 1,000 个赛季，比较统计结果 | 数值设计是用模拟器调出来的，引擎必须和它一致 |
| 加速模拟赛季 | 机器人小组把 33 天约 1 小时跑完，连续 3 次账本平衡、不需要人工干预 | 整季流程只能这样提前走一遍 |
| 应用商店隐私检查 | 同意隐私政策之前不发任何第三方请求；用到才申请权限；能注销账号；能找到隐私政策和 SDK 清单 | 做不到会被商店退回 |
| 你自己走一遍 | 用测试账号：注册 → 每日任务 → 开通 → 分组 → 进攻 → 复核 → 结算 | 代替内测 |

其余的（压力测试、真机矩阵、AI 指标）不设门槛，第一季在实际使用中观察，出问题就修。

**问题分级**：

| 级别 | 例子 | 多快修 |
|---|---|---|
| P0 | 记错账、数据丢失、孩子信息泄露、登录不了、赛季流程卡死 | 立即修；服务器当天更新，app 用应用内更新 |
| P1 | 某个玩法结算错误或做不完；大面积收不到通知 | 24 小时内 |
| P2 | 体验、文案、样式 | 下一次更新 |

## 4. 工作方式

- **代码仓库**：`xiyuefan-jpg/Zhiyouji`（私有）。
  - 第二十八轮状态：Claude 已经能读这个仓库，但**推送被拒绝**，因为 Claude 的 GitHub App 还没有这个仓库的权限。
  - 解决：在 https://github.com/apps/claude/installations/select_target 安装 Claude 的 GitHub App 并选中这个仓库；或者在 claude.ai 设置 → 连接器里重新连接 GitHub。
  - 开通之前，代码先提交在会话工作区的本地仓库里，开通后一次推上去。
- **会话之间怎么接上**：一个对话能装下的内容有限，装满了会被压缩，细节会丢。所以全部状态都放在仓库里：
  - `CLAUDE.md`：项目说明、文档位置、开发约定；
  - `PROGRESS.md`：做到哪了、下一步做什么、遇到的问题；
  - `docs/`：PRD 和设计文档的副本。
  - 任何一个新会话打开仓库，先读这两个文件就能接着做。
- **在手机上看效果**：写到学生端时，两种办法，到时候选：
  - 用 Expo 的云构建出安装包，装到你的手机上（需要一个免费的 Expo 账号）；
  - 在你的电脑上用 Claude Code 打开同一个仓库，直接在手机或模拟器上跑。
- **Vibe coding**：你不看代码。Claude 写、Claude 测；你用测试账号点一遍，有问题直接说。规则引擎和账本例外，必须有第 2 节的自动测试。
- **改规则**：能用参数改的，直接在管理端改。要改规则的，先在对话里复述确认 → 改 PRD 和决策日志 → 改引擎和测试 → 同步 Python 模拟器。
