# apps/admin

网页管理端（PRD 第 7 部分），给管理员和复核员用。React 18 + Vite + Ant Design 5。

```bash
npm run invite-admin -w @zhiyouji/server -- 邮箱 名字 admin   # 第一个管理员：打印邀请码
npm run dev -w @zhiyouji/server                               # 服务器 :3000
npm run dev -w @zhiyouji/admin                                # 管理端 :5174，打开 /invite?token=邀请码
```

正式环境：静态文件放 OSS + CDN（美国也能快速打开），接口地址用 `VITE_API_BASE` 指向内地服务器；登录凭证是 Bearer token，存在 sessionStorage（关掉标签页就退出）。

## 现在能用的

| 页面 | 说明 |
|---|---|
| `/invite?token=…` | 接受邀请：设密码 → 用验证器 App 扫二维码 → 输一次 6 位数字 → 开通 |
| 登录 | 邮箱 + 密码 + 两步验证码；30 分钟不操作自动退出，回到登录页并说明原因 |
| 看板 | "需要处理"：未读的管理端通知（例如计划事件失败）；统计等服务器接口 |
| 管理端账号 | 账号列表、邀请（生成一次性链接，7 天有效）、停用（立即下线）；只有管理员能看 |
| 查看记录 | 谁在什么时候查看、下载了哪个孩子的什么；按账号、孩子、日期筛选；只有管理员能看 |
| 通知中心 | 右上角铃铛；已读、全部已读 |
| 看板 `/` | 需要处理（快到时限的复核、待复核、卡住的每日任务、失败的计划事件、题库不足、未读通知）；今天的数字；各服第几天、进行中的争夺、下一次公布、前三名 |
| 复核 `/review` | 我的队列（按时限，快到时限标红）、请假；盲审一件作品（文字、文件和转写、辩论的立论、评分族各维度满分、AI 初评对照、评语和标记，交了不能改）；每日任务异常队列（通过 / 不通过、学科和子领域、难度、反馈） |
| 复核员看板 `/reviewers` | 每位复核员分到、待交、按时完成、超时按 AI 结算、平均用时、和第二人 / AI 的平均分差 |
| 赛季 `/season` | 赛季列表、新建（开营日只能选周日、可复制参数）、开放报名 / 退回报名中；参数表（改了保存为新版本，带说明和版本记录）；日历（上学日 / 休息日） |
| 玩家与分组 `/players` | 按手机号或昵称找孩子、开通（缴费备注）、报名名单（导出 CSV、撤销）、生成 / 换组 / 改组名 / 确认锁定分组、小组和阵营微信群二维码上传 |
| 赛季监控与干预 `/monitor` | 选服；总览、争夺（取消并退 / 不退粮草）、计划事件（改时间、重跑失败的）、账本（冲正）、人工干预（加减粮草或团队分、改地块主人、发放 / 收回法宝、设组长、退赛）、暂停 / 恢复、战报预览（隐藏一条）；每一步都要填原因 |
| 题库与评分 `/content` | 地块模板（一键导入 12 个、改名、顺序）、题目（筛选、新建 / 修改、启用 / 停用、JSON 批量导入）、题库不足的地块 |
| 内容与运营 `/ops` | 公告（发给所有孩子或某个赛季、定时、发出前可撤回）、内容安全队列（通过 / 删除；复核员"转给管理员"）、AI 配置（每个任务的模型、备用、影子、提示词版本）和最近 7 天的调用、出错率、费用、人工分减 AI 分 |
| 终局与导出 `/final` | 终局结算（填奖池）、奖学金发放表、赛季回顾（生成、统一发放）、数据导出（每日任务、作品和分数、账本、问卷）、家长的导出 / 删除申请 |

左侧菜单按第 7 部分的章节排好；复核员只看到第 0 节允许的部分（看板、复核、题库与评分、内容安全）。服务器发来的通知链接（`/reviews/<id>`、`/servers/<id>`、`/question-bank`、`/safety`）都能打开对应页面。所有时间同时显示北京时间和本地时间。
